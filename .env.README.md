# Security & Environment Setup

## Important: Environment Variables
This project requires a `.env` file in the root directory. **Never commit this file to version control.**

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

2. Fill in your actual credentials in the `.env` file

## Added Files:
- `.env.example` - Template for environment variables
- `.gitignore` - Already configured to ignore `.env`

## Security Note
The database credentials have been removed from README.md for security. Use environment variables instead.
