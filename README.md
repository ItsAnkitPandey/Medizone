# Medizone - A Medical E-commerce WebApp

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

# Live on [Medizone](https://medizonnetlify.app)

# New Version on [New Medizone](https://medzonnetlify.app)

## Features
- 🛒 Shopping cart functionality
- 🔐 User authentication (Login/Signup)
- 💊 Browse medicines by category
- 🤖 AI-powered chatbot assistant
- 📱 Fully responsive design
- ✅ Order checkout and tracking

## Installation

1. Clone the repository
```bash
git clone <your-repo-url>
cd medizone
```

2. Install dependencies
```bash
npm install
```

3. Create a `.env` file in the root directory (see `.env.example` for required variables)

4. Start the development server
```bash
npm start
```

## Environment Variables
See `.env.example` for required environment variables. Never commit your `.env` file to version control.
